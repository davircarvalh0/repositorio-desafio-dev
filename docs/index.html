A suíte envia requisições HTTP para a API e verifica status, conteúdo e regras de negócio. Também executa o seed para conferir os exemplos, a ausência de duplicações e a preservação de alterações. Um 400 pode ser um teste aprovado: recusar dados inválidos faz parte do comportamento esperado.
